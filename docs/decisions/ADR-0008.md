# ADR-0008: Review console dependencies

Status: accepted

- Python: `fastapi` and `uvicorn` serve the console API and the built
  frontend (declared in the stack as FastAPI). `httpx` is a dev dependency
  for FastAPI's TestClient.
- Frontend: `react` and `react-dom` (declared), built with `vite` and
  `@vitejs/plugin-react`. `@playwright/test` drives the end-to-end suite
  (declared as Playwright).
- Confirmed labels append to `data/training_set/confirmed_labels.jsonl`.
  Training reports their count but does not merge them yet: merging
  validation-period labels into training would change the Gate 1 numbers
  and the sealed comparison, so it waits for a decision on retraining
  cadence.
- End-to-end runs use `data/artifacts/e2e/` for labels and dispositions, so
  test decisions never enter the real label store.
