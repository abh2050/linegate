# ADR-0004: OpenAI for agents, pydantic tool schemas

Status: accepted

## Context

CLAUDE.md names the Anthropic SDK for agents. No Anthropic API key is
available in this environment; an OpenAI key is.

## Decision

- Agents call OpenAI chat completions with function calling through
  `linegate/agents/runtime.py::OpenAIClient`, model `gpt-5.4-mini`
  (`config/agents.yaml`). The runtime talks to an `LLMClient` protocol, so
  an Anthropic client can replace it without touching agents or tools.
- `pydantic` defines tool input schemas (declared in the stack).
- API keys live in `.env` (gitignored, mode 600) and are loaded by the
  runtime. They are never written to traces or committed.
- Token prices in `config/agents.yaml` are assumptions until checked
  against current OpenAI pricing; they only drive the budget cap.

## Leak decision authority

The warden's verdict is the stricter of the model's decision and a
deterministic rule over the three test results
(`linegate/model/guards.py::warden_verdict`). The model writes the finding;
it cannot approve what the rule quarantines, and it cannot decide before
all three tests have run.
