# ADR-0006: Evaluate acceptance measured against placebo noise

Status: accepted. Replaces the "min_delta_mcc and 2 of 3 seeds" rule from ADR-0003.

## Evidence

After three Gate 4 runs every evaluation scored below the Gate 1 baseline.
Controls on the same scoring path (`EnsembleScorer`):

| Run | MCC (3 seeds) | Avg precision |
|---|---|---|
| baseline | 0.2267 | 0.0753 |
| + 1 random column | 0.2196 | 0.0766 |
| + 2 random columns | 0.2107 | 0.0734 |
| + 3 random columns | 0.2279 | 0.0782 |
| + 4 random columns | 0.2201 | 0.0745 |

- The scoring path reproduces the baseline exactly and an all-NaN column
  changes nothing, so there is no pipeline bias.
- Any usable extra column reshuffles LightGBM's feature sampling and moves
  ensemble MCC with SD 0.0068 (range 0.017). Five seeds did not reduce it
  (SD 0.0086). With feature_fraction 1.0 a noise column raised MCC by 0.004.
- The Gate 1 figure of 0.2267 is a high draw from this distribution; the
  mean is 0.221.
- The old bar (+0.004 and 2 of 3 seeds) would have accepted a random column.

## Decision

- At search start, `EnsembleScorer.calibrate` runs the baseline plus
  `placebo_runs` random-column controls and caches the mean and SD of MCC
  and average precision (`data/artifacts/search/noise_reference.json`).
- A batch is accepted when MCC >= best + max(min_delta_mcc, k * SD_mcc) and
  AP >= best + k * SD_ap, with k = `noise_sd_multiplier` (2.0). The
  strongest placebo above fails this bar.
- The search starts from the placebo mean, not the single baseline draw.
- The runtime nudges an agent that stops early, up to `max_nudges` times,
  while evaluate calls remain and the stop rule has not triggered.

## Consequences

Accepted features must show a real effect of roughly +0.014 MCC together
with a matching gain in average precision. Fewer features will pass, and
those that do are unlikely to be noise.
