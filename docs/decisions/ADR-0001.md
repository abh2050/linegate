# ADR-0001: Gate 0 dependencies outside the declared stack

Status: accepted

## Context

CLAUDE.md declares the stack (DuckDB, Polars, LightGBM, Pydantic, Anthropic
SDK, FastAPI, React, pytest, Playwright). Gate 0 needs two things the stack
does not name: reading YAML config and downloading competition files.

## Decision

- `pyyaml` parses `config/*.yaml`. The standard library has no YAML reader.
- `kaggle` provides the CLI that downloads the competition files. It is
  invoked as a subprocess from `linegate/dataio/fetch.py` only, never
  imported, because importing it authenticates at import time.
- `hatchling` is the build backend so `uv sync` installs `linegate` as a
  package. It is a build-time requirement only.

## Consequences

Kaggle credentials (`~/.kaggle/kaggle.json` or `KAGGLE_USERNAME` /
`KAGGLE_KEY`) and acceptance of the competition rules are required to run
`make data`. Nothing else in the codebase depends on `kaggle`.
