# ADR-0003: Baseline v2 features and training protocol

Status: accepted. Supersedes the "First run" results in ADR-0002.

## Context

The Gate 1 v1 baseline scored validation MCC 0.156, with early stopping at
iteration 1. Diagnostics showed the trainer was sound (train AUC 0.78 vs
validation 0.61) and pointed at three causes:

- Validation positive rate is 0.31 percent against 0.73 percent in train,
  so the time-ordered split carries real drift.
- Numeric measurements alone plateau near AUC 0.61 on this split, whether
  raw (968 columns) or aggregated.
- `scale_pos_weight: auto` (about 137) plus early stopping on validation
  AUC stopped training almost immediately.

## Ablation (validation MCC, threshold chosen on validation)

| Change | MCC |
|---|---|
| v1 baseline, config params | 0.162 |
| regularized params, spw=1 | 0.172 |
| + per-station arrival, per-line span, station count | 0.169 |
| + categorical integer codes and per-station categorical counts | 0.227 |
| + per-station out-of-range counts (train p1/p99) | 0.151 to 0.216 |
| + route failure rate (out-of-fold target encoding) | 0.205 to 0.209 |
| + all 968 raw numeric columns | 0.186 to 0.228 |

Seed-to-seed spread on one feature set was about 0.02 MCC.

## Decision

- Feature set `baseline_v2`: the v1 set plus arrival, span, station count,
  integer codes for the 96 categorical columns with values in at least
  0.01 percent of train parts and two or more distinct values (chosen on
  train only), and per-station categorical counts. Absolute start time is
  carried only to define the early-stopping slice and is never a feature.
- Out-of-range counts, route target encoding, and raw numeric columns were
  left out: they did not help reliably.
- Early stopping runs on the latest 15 percent of train by start time, on
  average precision. Validation labels no longer choose the tree count.
- Three seeds are trained and averaged, because single-seed noise (0.02)
  exceeds the Gate 4 `min_delta_mcc` of 0.004.

## Result

Validation MCC 0.2267 (bootstrap 90 percent CI 0.195 to 0.261), per-seed
0.214 / 0.225 / 0.231, AUC 0.626, 445 features, 75 s end to end at 6.9 GB
peak RSS. With the threshold chosen on the train tail instead of on
validation, MCC is 0.2215, so threshold selection adds little optimism.

## Consequences

Gate 4 compares against 0.2267. Its minimum delta of 0.004 sits well inside
the bootstrap interval, so the search agent should be judged on repeated
seeds rather than a single run.
